# Before and after captions

Short captions for a before-and-after post, in your voice.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write five short captions for before-and-after grooming photos at [shop]. Facts: breed [ ], what we did [ ], how long [ ]. Voice: [paste a caption you like]. Use the dog's name only if I write "owner said yes". End with how to book: [link].
```

## How to use it

Ask owners at drop-off if you can post their dog.
