# Price by lot size

Prices weekly and biweekly mowing by lot size, with drive time.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Price mowing for [business]. Target per hour [$] per crew member, crew size [ ], minutes per lot size: small [ ], medium [ ], large [ ], drive time between yards [min]. Give weekly and biweekly prices and a minimum.
```

## How to use it

Re-run each spring.
