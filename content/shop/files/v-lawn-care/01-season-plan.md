# Season plan offer

A season plan with a clear price, what's included and the signup post.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write a season plan for [business]: [mows] mows from [month] to [month], plus [extras]. Price by lot size [ ]. Payment options [ ]. Then the signup post, a door hanger (40 words at most) and a reminder post two weeks later.
```

## How to use it

Post it in March, before the first mow.
