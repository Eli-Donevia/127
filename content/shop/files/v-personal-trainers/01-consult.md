# Consult script

A 30-minute consult that ends in a plan and a clear price, without pressure.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write a 30-minute consult script for [my business]. Sections: welcome (2 min), goals in their words (8), training history and injuries, with a note to get a doctor's OK where needed (5), schedule (3), the plan I'd suggest (5), packages and prices [ ] (5), next step (2). Questions to ask in each. No promises about results.
```

## How to use it

Print it. Write their answers on it.
