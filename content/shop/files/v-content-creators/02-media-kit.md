# Media kit

A one-page media kit from your real numbers and the deals you want.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write a one-page media kit for [channel]. Real numbers: followers per platform [ ], average views [ ], audience (age, location, top interests) [ ]. What I make: [ ]. Brands I'd fit: [ ]. Packages: [ ]. Contact: [ ]. Use only the numbers I gave you.
```

## How to use it

Update the numbers monthly. Send as a PDF.
