# Product page with a claims check

Writes a product page from texture, scent and ingredients, then flags any line that sounds like a medical claim.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write the product page for [product] from [brand]. Facts: texture [ ], scent [ ], key ingredients [ ], size [ ], how to use it [ ], price [ ].

Rules: describe how it feels, smells and is used. Never say it treats, cures, heals, prevents or repairs anything, and never name a skin condition. After the page, list any sentence you're unsure about and why.
```

## How to use it

Run it on every new product, and on old pages once. Ask a lawyer about anything the check flags.
