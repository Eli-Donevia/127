# Make version one in a weekend

Version one does one job, completely. Not ten jobs halfway.

## Scope it

Write the job in one sentence: "After using this, you'll have [a finished thing]." If you can't end the sentence with a noun, the product is too vague. "You'll have a pricing sheet with your numbers in it" is a product. "You'll understand pricing better" isn't.

## Build order

1. **Start from the version you already use with clients.** Your real template, real prompts, real checklist.
2. **Strip out your private details** and mark every blank someone has to fill in, the same way, every time ([like this] or {{like_this}}).
3. **Add a "Start here" file.** Three to five numbered steps. Most refunds come from people who didn't know where to begin.
4. **Add one worked example.** Your template filled in for a made-up business. People learn by copying. If it has money in it, label it "Example: made-up numbers".
5. **Test it on someone.** Give it to one person in your audience, watch them use it, and fix the first place they get stuck.

## Formats that travel

- Documents: PDF for reading, Markdown or Google Doc for copying.
- Spreadsheets: Google Sheets (with a "make a copy" link) and .xlsx.
- Notion: a duplicate link to a public template page.
- Design: Canva template links, Figma community files, or source files.
- Code and HTML: one file per piece, with comments where people change things.

## Make it look finished

A cover image, consistent file names (01-start-here, 02-..., in order), and the same fonts and colours in every file. Buyers judge the whole product by the first file they open.

## Prompt: turn your file into a product

```text
Here's a file I use with my own clients: [paste it].

Turn it into a sellable template for [who]:
1. Replace anything specific to me with clearly marked blanks in the format [like this].
2. Write a "Start here" section with five numbered steps.
3. Fill in one complete worked example for a made-up [type of business]. If it has money in it, label it "Example: made-up numbers".
4. List the three places a first-time user is most likely to get stuck, and add a one-line hint at each.
```
