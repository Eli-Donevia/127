# Gallery delivery email

Delivers the gallery with how to download, print and share, and asks for a review.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write the gallery delivery email for [client] from [my business]. Gallery link [ ], available until [date], how to download, where I recommend printing, how to credit me if they post, and one line asking for a Google review [link], no reward offered.
```

## How to use it

Send within your promised delivery time.
