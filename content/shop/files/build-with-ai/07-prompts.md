# The prompts

Every prompt from this course, plus the ones 127 uses most. Fill in the brackets.

## Spec from a voice note

```text
Here's a voice note transcript describing a feature I want: [paste].
Turn it into a spec with these sections: one line; what the person can do when it's done; done when (checkable); what stays the same; rules; open questions with who answers each.
Don't invent features I didn't mention. List anything you had to guess under open questions.
```

## Start a thread on one job

```text
You own one job in my project: [job]. Here's the spec: [paste]. Here are the project rules: [paste or link the shared folder].
Work on your own branch. Don't publish or merge. When you're done, hand over: what changed, how to switch it on, what you tested and the results, and anything that needs my decision.
```

## Build behind a switch

```text
Add [feature] behind a switch called [NAME] (off, admins, on; default off).
List the tests you'll write in plain sentences first, including what must NOT happen. Wait for my OK.
Then build it, run every test, and show me the results and how to view it as an admin.
```

## Explain what you just did

```text
Explain the change you just made as if I'm the founder, not an engineer: what someone using the product will notice, what could go wrong, and how we'd know. Under 120 words.
```

## Bug report to fix

```text
Here's what happened: [what I did, what I expected, what I saw, on which device]. Screenshot attached.
Find the cause before changing anything. Tell me the cause in one sentence, then fix it, add a test that would have caught it, and run every test.
```

## Design critique

```text
Here's a screenshot of my page at phone width. Critique it against these AI-made tells: rounded badges with a coloured dot; glows and blurred colour blobs; headlines with half the words in another colour; three identical icon cards in a row; gradient text; everything centred; vague words like "unlock", "elevate", "seamless".
For each problem, say exactly what to change. Then name the one change that would make it feel most like a real, premium brand.
```

## Copy check

```text
Check this copy against my rules: [paste rules]. Copy: [paste].
List each problem with the exact words and a rewrite. Don't change anything that already follows the rules.
```

## Handoff

```text
Write the handoff for the work in this thread: two or three sentences on what changed; how to switch it on and what stays off; what you tested with the results; what needs my decision. Plain words, no code unless I need to run it.
```

## Weekly review

```text
Here's what shipped this week: [list]. Here's what's waiting on me: [list].
Tell me the three decisions that unblock the most work, in order, each with your recommendation in one sentence.
```
