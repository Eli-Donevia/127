# Dispatcher Pack

Made by scripts/build-verticals.js from content/verticals/truck-dispatchers.json. Don't edit these files; edit the vertical and build again.

- Weekly carrier report
- Rate con check
- Service agreement outline

## Before you use these

- FMCSA's 2023 guidance: a dispatcher who works for more than one carrier and chooses which carrier gets a load is acting as a broker and needs broker authority. Handling money between shippers and carriers points the same way. The agreement outline sets which loads you find for each carrier (lanes, equipment) so you never choose between carriers for one load. Have a lawyer check it.
