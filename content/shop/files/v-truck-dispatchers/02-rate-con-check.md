# Rate con check

A checklist to read a rate confirmation for the things that cost a carrier later.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Read this rate confirmation and list, in plain words: pickup and delivery windows, the all-in rate and how it splits, detention and layover terms, lumper terms, TONU, payment terms, any fines or penalties, and anything that looks different from what was said on the phone: [paste rate con text].
```

## How to use it

Run it before your carrier signs. Ask the broker about anything it flags.
