# Weekly carrier report

Turns your load list into a one-page weekly report for each carrier.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Here are this week's loads for [carrier]: [paste load number, lane, miles, rate, deadhead, status]. Write a one-page report: totals (loads, loaded miles, gross, rate per mile, deadhead %), my fee at [%], one line per load, anything still owed (PODs, detention), and next week's plan in two lines. Plain and short.
```

## How to use it

Send Friday afternoon, the same format every week.
