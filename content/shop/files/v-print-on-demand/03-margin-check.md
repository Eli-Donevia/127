# Margin check

What a sale leaves after the printer's base price, shipping, fees and ads.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
My printer charges [$] base for a [product], shipping is [$], my store fee is [%], payment fee is [%]. I sell it for [$]. Show what one sale leaves, then what's left if I spend [$] on ads per sale. Table, then one sentence.
```

## How to use it

Run it per product before you run any ad.
