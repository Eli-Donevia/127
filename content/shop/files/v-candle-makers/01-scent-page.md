# Scent page

Describes one scent so a shopper can almost smell it: a place, a moment and the notes.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write the product page for [scent name] from [shop], a hand-poured [wax] candle.

Notes: top [ ], middle [ ], base [ ]. Size and burn time: [ ]. Price: [ ].

Give: a name line, two sentences that put the scent in a real place and moment (a kitchen in October, a cabin after rain), the notes in plain words, how it burns, and care in one line. No health or aromatherapy claims.
```

## How to use it

One per scent. Read it out loud; if it sounds like a perfume ad, cut a line.
