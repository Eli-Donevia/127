# Half-clean reel

The 15-second reel with the clean line through the dirt.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write a 15-second reel brief for a [surface] at [business]: the first second (the clean line), the sound, three shots, the reveal, on-screen words (six at most) and a caption with the town and price range.
```

## How to use it

Film every job. Post the best one each week.
