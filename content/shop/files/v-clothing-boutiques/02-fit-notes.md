# Fit notes for a piece

Writes honest fit notes from your measurements and how the piece wore on you or a model.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write fit notes for the [piece] from [boutique].

Facts: fabric [ ], stretch [none/some/a lot], length on a [height] model wearing size [ ], measurements per size [paste], how it fit when we tried it [your words].

Give: "How it fits" in three short lines, "Size up or down?" in one line, and care in one line. Plain words. Never "flattering on every body".
```

## How to use it

Paste the output under the product photos. Fit notes cut the returns that come from guessing.
