# Drop plan

Plans one drop from a list of pieces: the order they go live, a post for each and the email.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
I run [boutique], a clothing boutique for [who]. This week's drop: [list each piece with color, sizes and price].

Plan the drop:
1. The order the pieces go live and why (lead with the one most people will want).
2. One post idea per piece: what to film, the first line of the caption.
3. The drop email: subject line, three short paragraphs, one button.
4. A restock note for anything with fewer than [n] in a size.

Keep it in my voice: [paste a caption you wrote].
```

## How to use it

Run it on Sunday night with your list. Post the lead piece first.
