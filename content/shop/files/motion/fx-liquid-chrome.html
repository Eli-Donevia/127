127 Motion Pack · fx-liquid-chrome

Liquid chrome.

How to use it

Call liquidChrome(canvas, { base, mid, spec, amplitude, speed, scale, poster }). Colors are 0 to 1 RGB: spec is the highlight, so your brand color goes there. Use scale: 0.5 on phones. It pauses off screen and in hidden tabs, draws one still frame under reduced motion, and shows poster where WebGL is missing.

Prompt for an AI builder

Paste this, with this whole file attached, into Claude, Lovable, Bolt, v0 or Webflow's AI.
