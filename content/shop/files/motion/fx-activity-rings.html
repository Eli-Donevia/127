Progress you can see.

How to use it

Call activityRings(el, rings, { size, stroke, gap }), one ring per { label, current, target, unit, color, colorEnd }. It draws when scrolled into view and returns update(rings) to move them on. Great for a client dashboard, a habit page or a fundraiser.

Prompt for an AI builder

Paste this, with this whole file attached, into Claude, Lovable, Bolt, v0 or Webflow's AI.

Using the attached file, add activity rings to my page showing [three numbers with their targets]: the rings CSS in my stylesheet, a <div data-rings> where they go, and the module script at the end of <body> with my numbers.
