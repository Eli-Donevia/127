# 127 Motion Pack

18 moves, one file each. Open any file in a browser to see it, then follow "How to use it" at the bottom of the
page, or attach the file to Claude, Lovable, Bolt, v0 or Webflow's AI with the prompt it gives you.

- intro-assemble.html: Assemble intro
- intro-develop.html: Develop intro
- intro-pour.html: Pour intro
- intro-unfold.html: Unfold intro
- intro-type.html: Type intro
- intro-mask.html: Mask intro
- intro-stamp.html: Stamp intro
- intro-draw.html: Draw intro
- scroll-scrub.html: Scroll scrub
- scroll-pin.html: Scroll pin
- scroll-scene.html: Scroll scene
- alive.html: Alive at rest
- kit-reveal.html: Reveal kit
- fx-liquid-chrome.html: Liquid chrome
- fx-particle-swarm.html: Particle swarm
- fx-activity-rings.html: Activity rings
- fx-toast.html: Stacked toasts
- fx-sheet.html: Bottom sheet

Every move respects reduced motion (the page shows complete and still), works with JavaScript off, and adds a Pause
motion button wherever something loops.

file carries its license at the bottom. 127's own code here is yours to use on any site you make, for you or for
