127 Motion Pack · fx-particle-swarm

How to use it

Call await particleSwarm(canvas, { source, colors, progress }). Here it forms on arrival and scatters as you scroll on. source is { text, font }, { src: 'logo.svg' } or an image. swarm.progress(0..1) scatters or forms it (tie it to scroll, as here), or swarm.formIn(1200) plays it once. The cursor pushes points away. It caps points per screen size (2,200 on a phone) and shows the formed shape, still, under reduced motion.

Prompt for an AI builder

Paste this, with this whole file attached, into Claude, Lovable, Bolt, v0 or Webflow's AI.

Using the attached file, form my logo (logo.svg) out of particles as visitors scroll the first screen: a sticky full-screen canvas inside a 220vh section, the module script at the end of <body>, colors set to white and my brand color, and progress tied to how far the section has scrolled.
