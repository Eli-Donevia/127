Tell them it worked.

How to use it

Call toast(title, { description, action, duration }), or toast.success, toast.error, toast.loading, then toast.update(id, {...}). Up to three show; hover fans them out; swipe dismisses. It announces to screen readers.

Prompt for an AI builder

Paste this, with this whole file attached, into Claude, Lovable, Bolt, v0 or Webflow's AI.

Using the attached file, show a toast when my contact form sends: the toast CSS in my stylesheet, the module script at the end of <body>, and on submit a toast.loading("Sending…") that becomes toast.success("Sent. We'll reply today.") when the request finishes.
