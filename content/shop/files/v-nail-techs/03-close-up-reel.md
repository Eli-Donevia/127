# Close-up reel

A 10-second close-up reel brief for one set.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write a 10-second reel brief for a [set] at [business]: the first second (the hand turning in light), three close-ups, on-screen words (five at most), and a caption with the set name, price and how to book.
```

## How to use it

Film by the window after every set you love.
