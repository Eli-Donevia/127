# Set pricing

Prices sets by length, shape and art from your time and target hourly rate.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Price nail sets for [business]. Target per hour [$]. Time: short set [min], medium [ ], long [ ], extra for shapes [ ], art per nail by level [ ]. Product cost per set [$]. Give a menu and an art price guide with three levels.
```

## How to use it

Show the art guide when they send an inspo photo.
