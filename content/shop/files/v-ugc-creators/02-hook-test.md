# Hook test

Ten first-two-second hooks for one product, sorted by type.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write ten hooks for the first two seconds of a UGC video for [product]. Two each: a problem, a surprising use, a reaction, a comparison, a question. Each under ten words, and say what's on screen during it.
```

## How to use it

Film three, post the one that holds.
