# Carrier one-pager

A one-page carrier profile a broker can read fast: authority, equipment, lanes, insurance, contact.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Write a one-page carrier profile for [company]. MC [ ], DOT [ ], equipment [ ], lanes [ ], insurance [carrier and limits], years running [ ], how to reach dispatch [ ]. Plain layout, headings, no claims about on-time rates unless I give you the number.
```

## How to use it

Send it as a PDF with your W-9 and insurance certificate.
