# Edit brief from client notes

Turns a client's loose notes into an edit brief you can cut from.

## The prompt

Copy everything in the box into Claude, ChatGPT or Gemini. Fill in the [brackets] first.

```
Turn these client notes into an edit brief: [paste notes]. Give: the goal of the video in one line, the audience, length, the hook in the first two seconds, the structure, music and caption style, brand rules, and the questions I should ask before I start.
```

## How to use it

Send the questions back the same day; start cutting once they answer.
