# How to set up the Content OS in Notion

Ideas, Posts and Hooks as Notion databases, plus a repurpose checklist, under one home page.

## Import it (about 5 minutes, on a computer)

Notion import is not in the phone app.

1. Download **127-notion-content-os.zip**. Do not unzip it.
2. In Notion, open **Settings**, then **Import**. (You can also click **Import** near the bottom of the sidebar.)
3. Choose **Text & Markdown** and pick the ZIP. Markdown files become pages and CSV files become databases inside them.
4. Wait for the import to finish, then open **Content OS** in your sidebar. Drag it to where you want it in your workspace.

If the ZIP import puts the databases somewhere odd, import each CSV on its own: **Settings > Import > CSV**. Each one becomes its own database. Then drag it onto the home page.

## Set up first (10 minutes)

Notion brings every CSV column in as text. Change these property types by clicking the column name, then **Edit property > Type**.

**Posts**
- Status: **Status** or **Select** (Idea, Drafting, Ready, Scheduled, Posted).
- Platform: **Select** (Instagram, TikTok, YouTube, Email, LinkedIn, add yours).
- Publish date: **Date**. Pillar and Format: **Select**. Link: **URL**.
- Repurposed to: **Multi-select**.

**Ideas**
- Pillar: **Select** (Teach, Behind the scenes, Customer questions, Personal). Status: **Select** (New, Picked, Parked). Added: **Date**.

**Hooks**
- Type: **Select**. Used in: **Relation** to Posts, if you want to see which hooks you've used.

## Then add two views

1. In Posts, add a **Calendar** view by Publish date. This is your posting calendar.
2. Add a **Board** view grouped by Status to see what's drafting, ready and scheduled.

## Last step

Delete the rows marked (example). Keep the Hooks rows: they are patterns, not examples.

*Notion menu names change. These steps were checked in October 2026.*
