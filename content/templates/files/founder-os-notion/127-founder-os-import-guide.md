# How to import 127 Founder OS into Notion

Takes about 5 minutes on a computer. Notion's import is not available in the phone app.

1. Download **127-founder-os-notion.zip**. Don't unzip it.
2. In Notion, open Settings, then Import. You can also use Import in the sidebar.
3. Choose the ZIP option (or Text & Markdown) and pick the file.
4. Notion makes a **127 Founder OS** page with the databases and pages inside. Markdown files become pages and CSV files become databases.
5. Open each database and check the property types. Set Stage, Status, Type, Pillar and Format to Select, and every date column to Date.
6. Delete the example rows once you add your own.

If the ZIP import doesn't keep the folders, import the CSV files one at a time: Settings, Import, CSV. Each one becomes its own database.

*Notion menu names change. These steps were checked in October 2026.*
