# One-Page SOP

*A one-page SOP that turns a task you repeat into steps anyone, or any tool, can follow, so it stops living in your head.*

**Template** · Build track · Builder · 45 minutes

**You walk away with:** A tested one-page SOP for one repeated task, a named person or tool running it, and a three-run review that tells you when to let go.

**Use it:** In week 2 of your roadmap, right after your Hours Audit picks a repeat task, then again in week 3 when you hand it off.

**Pairs with:** Delegate Your First Task (playbook)

---

If a task lives in your head, only you can do it. This page gets it out. One task, one page, steps a new person could follow on day one.

Record yourself doing the task once with your phone's screen recorder, talking out loud. Fill in this page from the recording. If it runs past one page, the task is too big. Split it.

## Is this the right task?

Start with a task that is repeated, rule-based and low-risk if it goes wrong once. Tick all four before you write.

- [ ] It happens weekly or more.
- [ ] You can explain it without saying 'it depends' more than once.
- [ ] If it's done a little worse than you'd do it, nothing breaks.
- [ ] Handing it off frees real time every week.

> No task picked yet? Fill in the Hours Audit first. Tag every task only me, repeat or waste, then pick a repeat.

## Review the first three runs

Don't hover. Don't disappear. Check closely three times, fix the SOP each time, then step back.

| Run | Date | Where it went off | SOP fix | Pass at 80%? |
| --- | --- | --- | --- | --- |
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |

- Run 1: watch or check everything. Note every place they got stuck.
- Run 2: check the finished result only. Give one or two specific notes.
- Run 3: spot check. If it's 80 percent as good as you'd do it, that's a pass.
- Same question twice? The answer goes in the SOP, not in a text.

## Handoff check

- [ ] Record yourself doing the task once, talking out loud.
- [ ] Write the steps from the recording, not from memory.
- [ ] Save the SOP where the owner can always find it.
- [ ] Test it with the person or tool that will run it.
- [ ] Review the first three runs and fix the SOP after each one.
- [ ] Add a weekly spot check to your Weekly CEO Review.

> Handing it to a person? Agree on fair pay and credit up front, and start with one small paid test task. Check local rules or ask a professional before treating anyone as staff.
